# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复，以及服务时限整批拒绝、快照冻结、值班交接与刷新一致性。测试失败时会保留截图和 trace。

## 服务时限与值班交接台

审批节点扩展为「服务时限 + 值班 + 暂停日历」模型：

- **节点配置**：值班组、服务时限（工作分钟）、暂停日历；配置面板实时展示班次与暂停时段。
- **整批拒绝发布**：任一审批节点缺值班组、时限不是正数，或其值班组存在班次重叠，整批拒绝发布，不产生新版本；问题面板列出节点与具体冲突班次。
- **工作分钟计时**：仅值班时段计时，暂停日历（全天或时段）不计时，跨班次/跨天/周末连续累计；班次交接后剩余时限连续、不重置。
- **快照冻结**：发布时为每个审批节点冻结值班组班次、时限和暂停日历的不可变副本；运行中实例始终使用各自的旧快照，新发起的实例才使用新规则。
- **值班交接台（`/desk`）**：在办任务的剩余工作分钟、计时状态（值班中/班次间隙/暂停中）、时限截止、下次交接；可登记交接、发起新实例；侧栏展示值班组班次冲突与暂停日历。
- **持久化与一致性**：配置、快照和实例起点持久化到 `localStorage`，刷新后剩余时限一致；数据（`mock-data`）、纯计算（`src/lib/sla.ts`、`src/lib/validation.ts`）与界面（`src/pages`、`src/components`）分层。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。
9. 进入「值班交接台」，查看剩余工作分钟与计时状态，登记交接验证剩余连续；打开发布被拒绝的「用印申请」查看冲突班次；修改「差旅费用审批」时限并发布，观察运行中实例仍为 v2 快照而新实例使用 v3 新规则。

## 项目结构

- `mock-data/`：12 个流程、80+ 实例、8 个用户、6 个角色、5 个业务域、值班组、暂停日历及边界案例。
- `src/components/`：布局、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史、值班交接台。
- `src/lib/`：纯函数工作分钟引擎（班次、暂停日历、时限、剩余时间）与整批校验/快照冻结。
- `src/store/`：Zustand 全局状态、校验、发布（快照冻结）、复制、归档、恢复、发起实例与交接逻辑。
- `src/types/`：核心业务数据 TypeScript 类型。
- `scripts/verify-sla.ts`：工作分钟引擎的纯函数自检（班次重叠、跨班次、周末、全天/时段暂停、时限截止、剩余连续）。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
