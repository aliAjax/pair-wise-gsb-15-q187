# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。流程与实例状态通过 localStorage 持久化，刷新后配置、时限快照和剩余时限保持一致。

## 服务时限与值班交接台

审批节点扩展为服务时限节点：在编辑器配置面板中为节点选择**值班组**、**审批时限（工作分钟）**和**暂停日历**。

- **发布整批校验**：同组班次重叠、节点缺值班组或时限不是正数时，发布被整批拒绝，问题面板列出涉及节点与冲突班次。Mock 中 wf-1 缺值班组、wf-4 引用的 IT 值班组早班/中班重叠、wf-7 时限为 0，可直接演示。
- **工作分钟计时**：实例进入审批节点后按工作分钟消耗时限，暂停日历窗口不计时；超时实例显示已超时时长。
- **值班交接**：运行监控的实例详情即交接台，可将任务交接给其他值班组/班次，交接后剩余时限连续（不重置、不暂停），交接记录写入执行时间线。
- **时限快照**：发布时冻结快照（值班组、班次、时限、暂停窗口全部固化），运行中实例继续用旧快照，新实例（监控页“模拟新实例”）才用新规则；版本历史页可查看每个版本的快照内容。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布：wf-1 因缺值班组被整批拒绝，在审批节点配置值班组后再次发布，观察快照冻结提示。
7. 在 Dashboard 和 Workflows 检查状态及版本；进入版本历史查看 v3 时限快照。
8. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
9. 打开运行中实例（如 INS-2026-0025），查看服务时限面板与剩余时限，执行一次值班交接，确认剩余时限连续。
10. 点击“模拟新实例”，对比旧实例的 v1 快照与新实例的当前快照；刷新页面确认配置、快照和剩余时限一致。

## 项目结构

- `mock-data/`：12 个流程、80 个实例、8 个用户、6 个角色、5 个业务域、值班组/班次/暂停日历及边界案例（数据层）。
- `src/domain/`：纯计算层——工作分钟计时、剩余时限、班次重叠检测、发布整批校验、时限快照冻结。
- `src/components/`：布局、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控（值班交接台）、版本历史（界面层）。
- `src/store/`：Zustand 全局状态、校验、发布、交接、模拟实例及 localStorage 持久化（编排层）。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
